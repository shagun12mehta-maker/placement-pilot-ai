03 · Product Workflow

How the Candidate Experience Works

A seamless 4-stage simulation mimicking real-world FAANG and corporate campus recruitment.

Phase 01

Role & Track Setup

Candidate selects company track (TCS, Infosys, Amazon, Startups) and role (SDE-1, Data Analyst, Cloud Engineer).

Phase 02

Live Spoken Interview

Webcam and microphone stream audio via WebSockets to Gemini Live. Natural conversational back-and-forth.

Phase 03

Interactive Coding

Candidate solves problems in Monaco Editor. Gemini Vision reviews code live and asks candidates to verbally defend logic.

Phase 04

Actionable Scorecard

Instant breakdown of Conceptual Depth, Spoken Clarity, and Pacing with timestamped improvement suggestions.

User Experience: Zero friction, accessible on any standard laptop browser with standard webcam/mic

04 · Technical Architecture

Deep Google AI & Cloud Infrastructure

A scalable, serverless microservices architecture built exclusively on Google’s enterprise stack.

🧠 Google AI Intelligence Layer

  • • Gemini Live API: Low-latency bidirectional WebSocket voice streaming with realistic turn-taking.
  • • Gemini 1.5 Flash / Pro: Vision-based code AST inspection, complexity verification, and architectural whiteboard evaluation.
  • • Gemma: Lightweight local inference for acoustic telemetry, speech pacing, and filler-word detection.
  • • Google Agent Skills: Enforces deterministic interview state machines and objective rubric evaluation.

☁️ Google Cloud Infrastructure

  • • Google Cloud Run: Auto-scales FastAPI/Node.js microservices from zero to thousands of containers during campus drives.
  • • Cloud Firestore: Real-time persistence for live session state, dynamic questions, and instant scorecards.
  • • Cloud Storage (GCS): Encrypted storage for session code snapshots and downloadable PDF reports.
  • • Cloud CDN & Monitoring: Sub-50ms regional latency across India with automated telemetry and alerting.
Architecture: Resilient, auto-scaling, and HIPAA/FERPA privacy-compliant with 30-day data lifecycle purge
